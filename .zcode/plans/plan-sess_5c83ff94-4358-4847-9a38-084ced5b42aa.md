# Server-side export assembly: `export_*` RPC family (hybrid)

Convert the five multi-request join exports — **Kontrollen, Massnahmen, Populationen, Teilpopulationen, Arten** — to single server-side RPC calls. SQL does joins, value decoding, `zaehlungen` aggregation, derived columns and sorting; the client keeps file serialization (XLSX/CSV/KML via `exportModule`) and the output headers stay **byte-identical camelCase** (quoted aliases in the views). Deferred per decision: the `Accept: text/csv` path and the ~10 lighter join exports.

## 1. New file `sql/postgrest/createExportRpcs.sql` (idempotent, `CREATE OR REPLACE`)

Five views + five RPCs, following the `query_*` blueprint (`createQueryRpcs.sql:1767-1860`):

**Views** — `apflora.v_export_ap`, `v_export_pop`, `v_export_tpop`, `v_export_tpopmassn`, `v_export_tpopkontr`, each `WITH (security_invoker = true)` + `GRANT SELECT` to the 5 app roles. Flat one-row-per-record shape joining the base table → tpop → pop → ap → `ae_taxonomies`/`adresse`/werte tables, all `LEFT JOIN` (current JS uses `?? null` for missing parents). Column aliases are **quoted camelCase** reproducing each component's exact JS object keys, so headers don't change, e.g. `tax.artname AS "apArtname"`, `(select sw.text from pop_status_werte sw where sw.code = p.status) AS "popStatus"`, `a.start_jahr AS "apStartJahr"`, `adr.name AS "tpopEkfKontrolleur"`.

Key non-trivial columns:
- `avEmail`: `LEFT JOIN LATERAL (select u.email from apflora."user" u where u.adresse_id = a.bearbeiter limit 1)` — table name needs quoting; verify exact schema from `createTables.sql` during implementation.
- `v_export_tpopkontr."zaehlungen"`: lateral `coalesce(string_agg('Einheit: ' || coalesce(ew.text,'(keine)') || ', Methode: ' || coalesce(mw.text,'(keine)') || ', Anzahl: ' || coalesce(z.anzahl::text,'(keine)'), ' / '), '')` over `tpopkontrzaehl` + einheit/methode werte — empty list yields `''` like the JS `.join(' / ')`.
- `v_export_tpop."angesiedeltNachBeginnAp"`: `case when a.start_jahr is not null and a.start_jahr <> 0 and t.bekannt_seit is not null and t.bekannt_seit <> 0 and t.status in (200,201,202) then a.start_jahr <= t.bekannt_seit else null end` (JS truthiness semantics).
- Keep raw and decoded both where the JS has both (`status` raw + `statusDecodiert` text in tpop/kontrollen rows).
- No `label`/`_artname` helper columns — headers must match exactly.

**RPCs** — `apflora.export_<table>(p_filter jsonb default null) returns setof apflora.v_export_<table>`, `language plpgsql stable`, SECURITY INVOKER (default), copying the query_* filter trick:

```sql
v_where := apflora.compile_filter('apflora.<table>', 'tb', p_filter);
return query execute format(
  'select t.* from apflora.v_export_<table> t join apflora.<table> tb on tb.id = t.id where (%s) order by …', v_where);
revoke execute … from public;
grant execute … to the 5 app roles;
```

Fixed `ORDER BY` per export mirroring the current JS sort (artname asc, then popNr, tpopNr, datum; `nulls first` on numeric/date keys to mirror the JS `?? 0` / `?? ''` semantics). For `export_pop` (JS sorts by `ap.label`) use a correlated subquery: `(select apflora.ap_label(a) from apflora.ap a where a.id = t."apId") asc`. No p_order/p_limit/p_offset — exports always want everything.

RLS applies automatically: invoker-rights function + security_invoker views (incl. the freiwillig tpopkontr policy from `2026-11-13_freiwillig-tpopkontr-rls`) — covered by tests below.

## 2. Register the file

Add `sql/postgrest/createExportRpcs.sql` to `FILES` in `scripts/sql-files.sh` (after `createQueryRpcs.sql`). Then `npm run db:apply-sql` locally and sanity-check in psql (`select * from apflora.export_tpopkontr(null) limit 5`) and against `localhost:3000`.

## 3. Rewrite the five components

Each `onClick` collapses to: one `rpc('export_<table>', filtered ? { p_filter: <same atom value as today> } : {})` call → 0-rows warning → `exportModule({ data: rows, fileName: … })`. Delete the fetch cascades, inline type blocks, Map joins, decode maps, sort and enrichment code. Rows typed as `Record<string, unknown>[]` (exportModule's input type). Preserve exactly: filter atom shapes (Kontrollen passes the whole `treeTpopkontrGqlFilterAtom` value, the others pass `.filtered`), fileName suffix behavior (`Arten_gefiltert`/`Populationen_gefiltert` vs. no suffix for the others), `tableIsFiltered` disabled logic, queryState/notification UI. Expected shrink: Kontrollen.tsx 423→~60 lines, Massnahmen 343→~60, TPop 282→~70, Pops 180→~55, Ap 133→~55.

## 5. Parity verification (acceptance criterion)
