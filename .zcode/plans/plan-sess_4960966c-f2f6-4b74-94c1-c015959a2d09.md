# Leaflet 2 migration on branch `leaflet2`

## Corrected premises (research findings)

- **ps runs `leaflet 2.0.0-beta.2` + `react-leaflet 5.0.0`** (not "react-leaflet v2"). It works via 4 tricks we'll copy: npm override `"leaflet": "$leaflet"` (react-leaflet 5 pins peer `^1.9.0`), a postinstall patch of `@react-leaflet/core` (`DomUtil.addClass/removeClass` → `classList`, removed in Leaflet 2), a `leaflet-v1-type-compat.d.ts` type shim, and a vendored patched geoman build. react-leaflet **v6 (6.0.0-alpha.0)** is in active dev on the `next` branch (updated to beta.2 on 2026-11-07) but unpublished — our patch/shim is throwaway, we switch when v6 ships.
- **markercluster**: the original repo was *revived* — `leaflet.markercluster@2.0.0-beta.1` (2026-11-04), ESM, own TS types, supports leaflet `^1.9 || ^2.0.0-beta.1`. Use it instead of the KristjanESPERANTO fork (fallback if it proves buggy: `@kristjan.esperanto/leaflet.markercluster@3.0.3`, Leaflet-2-only). Either way **drop `react-leaflet-markercluster`** (5.0.0-rc.0, untouched 2 years, no v2 story) for a small first-party `ClusterGroup` on `@react-leaflet/core` (same pattern as the existing `SafePane`).
- **leaflet-draw is a blocker you didn't mention**: dead since 2018, cannot run on Leaflet 2 at all. Replace with **ps's vendored patched geoman** (upstream PR #1602 + 4 documented patches) — copy tarball + README from ps. Drop when geoman ships official v2 support.
- **leaflet-measure**: dead (2018, repo dormant, zero v2-ready alternatives in the ecosystem). Build our own — modest scope.
- **leaflet-easyprint**: dead (2017/2022, no v2 alternative). Build our own — easyprint is internally just **dom-to-image capture + popup with `@page` CSS + `window.print()`**, trivially replicable with the maintained `html-to-image` package.
- **proj4leaflet**: effectively unused in apf2 (side-effect import only, CRS code commented out, map runs on default EPSG:3857) → remove. Standalone `proj4` stays for coordinate display.
- `@types/leaflet` is uninstalled for v2 (Leaflet ships its own types); also drop `@types/leaflet-draw`, `@types/proj4leaflet`.

## Phase 1 — Core swap (commit 1)

1. Branch `leaflet2` off master.
2. package.json: `leaflet@2.0.0-beta.2`; overrides `"leaflet": "$leaflet"`; remove `@types/leaflet`, `@types/leaflet-draw`, `@types/proj4leaflet`, `proj4leaflet`, `react-leaflet-markercluster`, `leaflet.markercluster`, `leaflet-draw`, `leaflet-measure`, `leaflet-easyprint`; keep `react-leaflet@5.0.0` + `@react-leaflet/core@3.0.0` (base for our custom components); add `postinstall` running `scripts/patch-react-leaflet.mjs` copied from ps.

5. Factories → constructors: `divIcon/point/marker/icon/circleMarker/popup/geoJSON/FeatureGroup(...)` → `new DivIcon/Point/Marker/Icon/CircleMarker/Popup/GeoJSON/FeatureGroup(...)`.
6. Rename mouse → pointer events (`mousemove`→`pointermove` etc.) in `CoordinatesControl`, `ClickListener`, `Tpop`, `MapPersister`; `click`/`dblclick`/`contextmenu`/`moveend` unchanged.

8. Verify map renders: base layers (OSM, Swisstopo WMTS/WMS), GeoJSON overlays, WMS overlays, panes/`SafePane`, scale/zoom controls.

## Risks

- Leaflet 2 is a beta (beta.2 released 2026-11-06); react-leaflet 5 + Leaflet 2 is unsupported — we run on ps's proven patch/shim until react-leaflet v6 publishes.
- apf2 exercises more react-leaflet surface than ps (`ScaleControl`, `ZoomControl`, `createControlComponent`, `Pane className`) — verified early in Phase 1.
- Upstream markercluster beta.1 is 4 days old — fork 3.0.3 is the drop-in fallback.
- `SwitchScaleControl` port needs runtime verification (`DomUtil.create`, `whenReady`, `crs.scale()` under v2).
